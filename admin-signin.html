Separate admin website

Sign in to the MechGo operations portal.

This admin site is kept separate from the driver and mechanic experience. After sign-in, it opens a private dashboard where you can review registrations, support complaints, booking activity, and verification submissions.

Registrations See who joined MechGo on the driver side and the mechanic side.
Support queue Track complaints, billing issues, safety flags, and app problems in one place.
Verification review Check submitted driver documents and move them through approval or rejection.

Production path

Demo admin credentials have been removed from the public frontend. Create the first admin through the protected API bootstrap endpoint before using this portal in a real environment.
